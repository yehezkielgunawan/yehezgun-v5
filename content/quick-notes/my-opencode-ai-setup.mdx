*Updated November 2026.*

When I first wrote this note in August, I was still on OpenCode V1 and splitting
work between Sol, Terra, and Luna. Now I’m on OpenCode V2 and using GPT-6.2 Sol.
But the setup change I wanted to write down was about tools. I used to keep a
separate MCP just to read PDFs. I don’t need it anymore, so I’m down to three.

## Setup snapshot

| Component | Current setup |
| --- | --- |
| OpenCode | `2.3.2` |
| Model I’m using now | `openai/gpt-6.2-sol` |
| MCP servers | GitHub, Context7, CodeGraph |

## The MCP servers I use

### GitHub

I use this when the answer is on GitHub, like a review comment on a PR or the
discussion in an issue. If I already know the PR number, I’ll ask for that PR
instead of asking the model to go through the whole repo.

### Context7

I use Context7 when I want to check what the docs say for the version I’m
working with. For example, if I’m checking a Next.js caching option, I’ll ask
about that option first. I don’t need routing and deployment docs in the same
answer.

### CodeGraph

For a repo that already has a CodeGraph index, I start here when I want to know
what calls a function or which files a change might affect. It gives me the
relevant code and how it connects.

### What happened to PDF Reader?

I used to keep `pdf-reader` around just to open PDFs. Now I can attach a PDF
directly in OpenCode, so I took it out of my setup. One thing to check if you
try it: the model you pick needs to
[support PDF input](https://opencode.ai/docs/attachments#formats).

## Where Superpowers fits

I still use Superpowers when a task needs a plan or a proper debugging pass.
And if I split the work, I keep each task small enough to check on its own.
Two agents editing the same file usually means more work for me later.

## Public-safe OpenCode configuration

Here’s just the Context7 entry as an example. In V2, server entries go under
`mcp.servers`. I keep the API key in an environment variable and reference it
from the config.

```json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "servers": {
      "context7": {
        "type": "remote",
        "url": "https://mcp.context7.com/mcp",
        "oauth": false,
        "headers": {
          "CONTEXT7_API_KEY": "{env:CONTEXT7_API_KEY}"
        }
      }
    }
  }
}
```

OpenCode normally reloads config changes after you save, so there’s no need to
restart it for this. The [MCP docs](https://opencode.ai/docs/mcp-servers) have
the setup for local servers and remote servers that use OAuth.
