# Yehezgun-v5

This is the 5th iteration of my personal website.

## Requirements

- Node.js 24 LTS
- pnpm 11

Install the required Node.js version with nvm, then enable the package manager declared by this repository:

```bash
nvm install
nvm use
corepack enable
corepack install
pnpm install
```

## TechStacks

- [Next.js](https://nextjs.org)
- [React & Typescript](https://react.dev)
- [Tailwind CSS](https://tailwindcss.com)
- [Daisy UI](https://daisyui.com)
- [Content Collections](https://www.content-collections.dev/)
- [React Giscus](https://giscus.app/)

## Notes for Mermaid Diagram

- Use ````mermaid-overflow```` to make the diagram always scroll horizontally.
- Use ````mermaid-fit```` to make the diagram always fit to the container width.
- Use ````mermaid-default```` to make the diagram responsive.
